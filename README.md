# StayN

StayN is a web-based accommodation booking platform built using React and Vite.

## Technologies Used
- React.js
- Vite
- JavaScript
- Material UI

## Features
- Accommodation browsing
- Guest selection
- Booking interface

## Installation

1. Clone the repository.
2. Install dependencies:

   `npm install`

3. Start the development server:

   `npm run dev`

4. Open the local URL displayed in your terminal.
